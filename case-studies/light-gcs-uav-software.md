# Light GCS / UAV Software Case Study

## Overview

This case study represents my experience with UAV Ground Control Station workflows, Qt/QML user interfaces, C++-based desktop application work, telemetry/log analysis, mission-oriented UI design, and field-driven debugging.

The goal is to show how my UAV software background strengthens my ability to build complex real-time interfaces and operational tools.

## Problem Space

A Ground Control Station needs to help operators understand aircraft state, mission progress, safety status, and flight data quickly. The interface must support:

- mission planning,
- map-based workflows,
- telemetry/status indicators,
- mode awareness,
- video/map-oriented layouts,
- field feedback and debugging,
- log review and operational reporting.

## UI / System Thinking
